# Mohammed Ashiq A — Personal Portfolio

Production-ready, ultra-premium personal developer portfolio for **Mohammed Ashiq A**, Cloud & DevOps Engineer. Built with React 19, TypeScript, Tailwind CSS v4, and Framer Motion.

## 🚀 Key Features

- **Modern Aesthetic**: Glassmorphism paneling, vibrant HSL/OKLCH color gradients, glowing borders, and dark mode design tokens.
- **Interactive Canvas Particles**: Lightweight GPU-accelerated particle canvas reactively responding to mouse movement.
- **Cloud & DevOps Focus**: Dedicated sections detailing Linux Administration, Docker Containerization, Nginx Virtual Hosting, and Prometheus/Grafana Monitoring Stacks.
- **Project Showcase**: Detailed cards and modal architectures for:
  1. *Video Call Sign Language Translator* (AI & Computer Vision)
  2. *Linux System Administration* (Systems & Bash Automation)
  3. *Nginx Virtual Hosting* (Web Servers & Reverse Proxies)
  4. *Server Monitoring Stack* (Observability with Grafana, Prometheus & Netdata)
- **Hanging Lanyard ID Pass**: Interactive 3D spring pendulum profile card physics.
- **Interactive Contact Hub**: Direct mail client & WhatsApp message generator + social links (LinkedIn, GitHub, Instagram, YouTube, Telegram).
- **Resume Generator**: Built-in dynamic HTML resume builder & automatic downloader.
- **Full SEO & Accessibility**: Semantic HTML5, JSON-LD Schema.org metadata, Open Graph cards, ARIA labels, and responsive layout across all device viewports.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite 7
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism Utilities
- **Animations**: Framer Motion 12
- **Icons**: Lucide React + React Icons

## 💻 Local Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```
